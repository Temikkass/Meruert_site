# Инструкция для владелицы сайта

Что здесь лежит:

| Файл | Что это |
| --- | --- |
| `Как наполнять сайт - инструкция.pdf` | готовый файл, который отправляют клиенту |
| `manual.html` | исходник — правится он, PDF пересобирается из него |
| `manual.print.css.html` | стили только для печати: формат A4, шрифты, запрет разрывов внутри блоков |

Текст описывает ту же панель, что и `docs/admin-guide.ru.md`, но написан для
человека без технического опыта и включает раздел про политику
конфиденциальности. Правьте их вместе, иначе они разойдутся.

## Как пересобрать PDF

Нужен Chrome. Скрипт склеивает `manual.html` с печатными стилями и печатает
результат в PDF:

```bash
npm run manual:pdf
```

Готовый файл кладётся сюда же, поверх старого.

## Почему в PDF другие шрифты

`manual.html` использует шрифты сайта (Plus Jakarta Sans, Inter, Manrope) —
так выглядит веб-версия. Chrome в режиме печати не подгружает веб-шрифты, и
подставить их в PDF не получается, поэтому печатная версия свёрстана на
шрифтах, которые есть в системе и полностью поддерживают кириллицу: Georgia
для заголовков, Segoe UI для текста, Consolas для примеров. Это осознанный
выбор, а не случайная подмена — см. `manual.print.css.html`.
